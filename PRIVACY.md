# GhostAccess privacy notice

GhostAccess is designed to work on the device. It does not include analytics, advertising, an account system, a network client, or a server.

## Information the app reads

With the user’s explicit Android Usage Access setting enabled, GhostAccess reads the package name, app label, granted permission names, and Android-reported last-use time for launchable installed apps. The app uses this to identify apps unused for 90 days or longer that still have sensitive permissions.

The optional file check reads only documents or a folder the user chooses in Android's system picker. It checks a limited set of exposed-secret patterns and reports the file name plus the type of possible secret. It never displays, saves, or transmits the matched value.

## Sharing and retention

GhostAccess does not send scanned information off the phone. Scan results are displayed in memory and disappear when the app process is closed. It does not create a device scan history.

## Controls

The user can decline Usage Access, disable it later in Android Settings, choose individual files or one folder, cancel document selection, and review each flagged app in Android's app settings. GhostAccess never changes another app's permissions itself.
